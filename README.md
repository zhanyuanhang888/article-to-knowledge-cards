# 文章转知识卡片

把长文章自动转成小红书风格竖版知识卡片（750×1000，3:4）的**纯前端工具**。

## 特点

- **零依赖、零后端**：单个 `index.html`，双击即可用浏览器打开
- **本地处理**：文章不上传任何服务器，隐私安全
- **自动提取要点**：按段落与中文标点（。！？；）智能切分，去重、过滤短句
- **竖版卡片**：适合小红书 / 朋友圈 / 公众号配图
- **一键导出**：支持单张下载和批量导出 PNG

## 使用方法

1. 用浏览器打开 `index.html`
2. 在左侧粘贴文章正文（可选填主标题、底部署名）
3. 设置「每卡要点数」（1–6）和主题色（如 `#ff2442`）
4. 点击「生成卡片」，右侧实时预览
5. 点击单张「下载」或「导出全部 PNG」

## 卡片样式

- 顶部主题色块 + 标题
- 中部白色区域展示编号要点
- 底部主题色条显示署名与页码

## 技术说明

- 原生 HTML + CSS + JavaScript，无需 npm / 构建步骤
- 使用 Canvas API 绘制卡片，无第三方库
- 发布后可直接作为静态站点访问
